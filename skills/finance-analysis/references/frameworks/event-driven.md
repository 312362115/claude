# 事件驱动分析（Event-Driven）

> **A_event 标签触发必跑 framework**。重组 / 并购 / 退市 / 商誉减值 / 业绩对赌 / 实控人变更 / 重大监管—— 事件驱动期标的的胜负手在"事件能否兑现 + 兑现时点 + 路径溢价"，不在静态估值。
>
> 核心命题：**事件不是单点冲击，是时间轴上的多节点博弈**。每个节点价格反应不同，每个节点都有概率分布，每个节点都有跟进 / 退出动作。
>
> **认知基础**：致尚 301486 案例直接教训 ——「静态 EV 模型只算终点收益，漏算路径中的期间溢价」是 0.3.2 沉淀的 L2 模型层根因。本 framework 从根上修复：用**节点 EV 时间轴**取代终点 EV。

---

## ⚡ When to Use / When NOT to Use（路由前必读）

| ✅ When to Use | ❌ When NOT to Use |
|---|---|
| A_event 标签触发（重组 / 收购 / 退市 / 商誉 / 对赌 / 实控人）| **稳态经营公司（E_value）** → 走 valuation-relative / DCF |
| 公告披露 6 个月窗口内（停牌 → 完成交割）| 单纯财报季业绩兑现（无并购 / 重组）→ earnings-deep-dive |
| ST / *ST 警示期（退市风险评估）| 主升浪纯题材炒作（B_momentum 强档无事件）→ technical-pattern + capital-flow |
| 商誉 / 总资产 ≥ 10%（减值雷敏感）| F_cyclical 周期股景气拐点 → top-down-selection |
| 业绩对赌期最后 1 年（兑现 / 不兑现关键节点）| 加密货币 / DeFi 协议事件（机制完全不同）→ 0.5.0 crypto-thematic |
| 实控人变更 / 控股权拍卖 ± 6 个月窗口 | 已停牌 > 6 个月（流动性枯竭）→ 等复牌 |
| 重大诉讼未结 / 监管立案 | 已平仓且事件落地 > 12 个月 → 退本 framework |

**强制路由触发条件**：asset-type-classifier 输出包含 A_event 标签时，**本 framework 是必跑项**。跳过 = 0.3.2 流程违规。

## 1. 决策树

```
输入：标的 + asset-type-classifier 输出（含 A_event）
↓
Step 1: 事件类型识别（7 大类）
  ├─ 重组（资产重组 / 借壳上市 / 业务剥离）
  ├─ 并购（主动收购 / 被收购 / 反收购）
  ├─ 退市（*ST / ST / 强制退市 / 主动退市）
  ├─ 商誉减值（高商誉 + 对赌期）
  ├─ 业绩对赌（对赌期 / 兜底方 / 补偿能力）
  ├─ 实控人变更（控股权转让 / 国资入主 / 拍卖）
  └─ 重大监管（立案调查 / 处罚 / 诉讼）
↓
Step 2: 时间轴节点定位
  ├─ 当前在哪个节点（停牌 / 预案 / 受理 / 过会 / 完成）
  ├─ 距下个节点 X 天
  ├─ 历史同类事件该节点典型反应
  └─ 是否处于"信息真空期"（节点之间预期博弈）
↓
Step 3: 兑现概率评估
  ├─ 历史同类事件兑现率（A 股 / 港股 / 美股 各有数据）
  ├─ 当前事件特殊性调整（控股股东支持度 / 监管口风 / 对赌方资质）
  └─ 联合概率（多事件并行时）
↓
Step 4: 路径 EV 模型（节点时间轴）
  ├─ 每节点的概率 × 收益贡献
  ├─ 期间高点 EV vs 终点 EV
  └─ 时间维度匹配（用户持有期 vs 事件完成期）
↓
Step 5: 输出事件附录（嵌入决策卡）
  ├─ 当前节点 + 距下节点天数
  ├─ 兑现概率 + 联合概率
  ├─ 各节点路径 EV
  ├─ 跟进 / 退出触发条件
  └─ 黑天鹅风险清单
```

## 2. 事件 7 大类型 + 兑现概率历史数据

### 2.1 重大资产重组（A 股）

**典型时间轴**：

```
停牌（10 个交易日）
  ↓
复牌（首日 +20% / -20% 概率高）
  ↓
重组预案披露（停牌后 30 日内必披露）
  ↓
证监会受理（预案后 1-3 个月）
  ↓
证监会反馈意见（受理后 30 日内）
  ↓
回复反馈意见（公司 30 日内）
  ↓
证监会发审会过会（受理后 3-6 个月）
  ↓
正式批复 + 完成交割（过会后 1-3 个月）
```

**历史兑现概率**（中国证监会披露 + 学术研究）：
- **重大资产重组过会率**：~75%（2018-2024 平均）
- **借壳上市过会率**：~60%
- **跨界并购过会率**：~50%（监管收紧后 2024 年 ~40%）
- **同行业并购过会率**：~85%（监管鼓励产业整合）
- **过会后撤回 / 终止率**：~5%

**节点价格反应**（典型）：

| 节点 | 反应 | 解读 |
|---|---|---|
| 停牌前 5 日 | +5% ~ +15% | 提前消息泄露 |
| 复牌首日 | +20%（涨停）/ -10% | 视方案优劣 |
| 预案披露 | ±10%（再次反应）| 方案细节决定 |
| 证监会受理 | +3% ~ +5% | 进度肯定 |
| 反馈意见 | ±5% | 取决于反馈严厉度 |
| 过会 | +5% ~ +10% | 兑现窗口 |
| 完成交割 | -5% ~ +5% | 利好出尽 / 业绩并表 |

---

### 2.2 主动收购 / 被收购

**A 股要约收购**：
- 要约期 30-60 日
- 控股股东接受率 ≥ 50% = 完成
- 历史完成率：~70%

**港股要约**：
- 强制全面要约（持股 ≥ 30% 触发）
- 接受期 21 日
- 完成率：~80%

**美股 SPAC DeSPAC**：
- DA 投票通过率：~80%
- 平均合并完成时间：12-18 个月
- DeSPAC 后 6 个月跌破发行价概率：~70%（Lockup 抛压）

**节点反应特点**：
- 要约价披露 → 股价快速向要约价靠拢
- 反收购方案出现 → 高度博弈期，波动放大
- 反垄断审查通过 → 最后兑现窗口

---

### 2.3 退市风险（A 股）

**触发条件**：
- 净资产为负 / 营收 < 1 亿 / 连续 3 年亏损
- 财务造假 + 监管立案
- 股价连续 20 日 < 1 元（面值退市）

**兑现概率**：
- *ST 摘帽率：~30%（重组拯救）
- *ST 退市率：~70%
- 财务造假退市率：~95%（监管收紧后）
- 面值退市率：~85%（一旦触发 1 元线）

**节点反应**：
- *ST 警示 → -30% ~ -50%
- 退市决定 → 进入退市整理期 -50% ~ -70%
- 退市整理期最后 5 日 → 残值博弈

**铁律**：本 skill **禁止参与已 *ST 标的的"重组拯救"博弈**。EV 期望负、波动极大、流动性枯竭三重否决。

---

### 2.4 商誉减值（A 股 / 港股）

**风险信号**：

| 信号 | 阈值 | 解读 |
|---|---|---|
| 商誉 / 总资产 | ≥ 10% | 高商誉警示 |
| 商誉 / 净资产 | ≥ 30% | 极高减值风险 |
| 业绩对赌期最后 1 年 | — | 减值高发期 |
| 标的近 3 年净利下滑 | > 20% | 减值倒计时 |
| 同行业整体景气下行 | — | 系统性减值风险 |

**减值兑现概率**（历史经验）：
- 对赌期 3 年内业绩不达预期：~50%
- 业绩不达 → 商誉减值：~80%
- 减值幅度 = 商誉 × (1 - 实际业绩 / 承诺业绩)

**节点反应**：
- 减值预告披露 → -20% ~ -40%（高商誉股一日杀）
- 实际减值确认 → 预期已 price-in，反应较小
- 减值后估值修复 → 6-12 个月内回升 30-50%（如果业务本身仍可）

---

### 2.5 业绩对赌

**典型对赌结构**：
- 对赌期：3 年（最常见）/ 5 年
- 兜底方：标的方原股东
- 补偿方式：现金 / 股票 / 业绩对应商誉减值
- 对赌业绩：3 年累计 X 亿净利 / 年 Y 亿净利

**兑现率历史数据**：
- 对赌期 3 年完整兑现率：~55%
- 第 1 年达成率：~80%（缓冲期）
- 第 2 年达成率：~65%
- 第 3 年达成率：~50%（前两年透支后冲刺）

**关键风险**：
- 对赌方净资产 < 补偿金额 → 兜底失效
- 对赌方公司主体已注销 / 失联 → 兜底失效
- 致尚案例：恒扬数据对赌方海纳天勤净资产 1129 万 / 2024 净利 -167 万 → **兜底 ≈ 零**

---

### 2.6 实控人变更

**典型路径**：
- 控股股东主动转让（协议转让 / 大宗）
- 司法拍卖（控股股东债务问题）
- 国资入主（地方国企整合 / 战略投资）
- 一致行动人解除（控股权稀释）

**节点反应**：
- 公告日 → 立即 +5% ~ +20%
- 完成交割 → 实质利好兑现
- 新实控人首份业务调整公告 → 方向决定后续

**成功率**：
- 协议转让完成率：~85%
- 司法拍卖流拍率：~30%（首拍）
- 国资入主完成率：~75%

---

### 2.7 重大监管 / 诉讼

**事件类型**：
- 立案调查 → 长期不确定性（6-24 个月）
- 行政处罚 → 罚款 / 警告 / 责令改正
- 集体诉讼（A 股证券集体诉讼制度）→ 赔付期长

**典型反应**：
- 立案公告日 → -5% ~ -20%
- 处罚落地 → 视严厉程度，温和处罚反而 +5%（"利空出尽"）
- 集体诉讼一审判决 → 视赔付额，重大判决 -20%+

**铁律**：立案调查期间标的 EV 高度负偏，仅在"处罚已落地 + 业务影响有限"明确后再启动 valuation framework。

## 3. 路径 EV 模型 — 节点时间轴

### 3.1 与静态 EV 的区别

**静态 EV（错）**：
```
EV = Σ (终点情景概率 × 终点收益)

例（致尚原决策卡）：
  全部兑现 24% × +30% + ... = -5.9%
```

**问题**：完全忽略路径中的期间溢价。

**路径 EV（对）**：
```
路径 EV = max(节点 i 的期间累计 EV, ..., 终点 EV)

例（致尚 4/28 视角）：
  停牌 → 4/8 → 公告日已发生
  复牌 → 4/21 → 已发生 +20%
  当前节点 → 4/28（决策日）
  下一节点 → 7/28 重组过会判定（T+3）
  
  4/28 → 7/28 节点路径分布：
    主升浪节奏延续 25% × +30% = +7.5%
    震荡 35% × 0% = 0%
    回调 25% × -10% = -2.5%
    重组延期黑天鹅 15% × -25% = -3.75%
  
  路径 EV = +1.25%（不算正，但远好于 -5.9%）

  关键：路径中任意一日的高点（如 5/7 实测 +22.7%）才是真实卖出窗口。
```

### 3.2 节点 EV 计算模板

每个事件节点需填以下字段：

| 字段 | 说明 |
|---|---|
| 节点名 | 复牌 / 预案 / 受理 / 过会 / 交割 |
| 距今天数 | 天 |
| 该节点典型反应（历史均值） | ±X% |
| 该节点兑现概率 | X% |
| 节点 EV 贡献 | 概率 × 反应 |

**累计路径 EV** = Σ 节点 EV 贡献。

## 5. 事件强度等级 + 决策建议

| 总分 | 强度等级 | 含义 | 决策方向 |
|---|---|---|---|
| ≥ 80 | 高确定性事件 | 兑现概率 > 80%，路径 EV 显著正 | 跟进 / 埋伏 |
| 60-80 | 中等确定性 | 兑现概率 60-80%，需路径 EV 验证 | 小仓位试探 |
| 40-60 | 低确定性 | 兑现概率 < 60%，仅短期博弈 | 仅技术派 / 不参与 |
| < 40 | 不确定 / 风险占优 | 路径 EV 负偏 + 黑天鹅风险 | 避开 |

**铁律**：事件分 < 60 + asset_tags 含 A_event → **决策不能 buy**，最多 watchlist 等下一节点。

## 6. 执行纪律

### 6.1 三条铁律

**铁律 1：不在节点之间的"信息真空期"加仓**
- 节点之间股价主要由情绪推动，方向难判
- 加仓时点应卡在节点 ± 3 日（信息确定性最高）

**铁律 2：节点利好兑现后立即评估"利好出尽"**
- 重组过会 / 收购完成等节点反而是减仓窗口
- 新预期填充前，旧预期已 price-in

**铁律 3：商誉 / 总资产 > 10% 标的，业绩对赌期最后 1 年禁止 buy**
- 减值雷高发期，单日 -30% 不罕见
- 等减值落地 + 业务恢复确认再考虑

### 6.2 黑天鹅清单（必查）

- 监管口风突变（"窗口指导"叫停）
- 反竞争方案出现
- 标的方关键人员离职 / 失联
- 控股股东司法冻结 / 限制消费
- 财务造假传闻 + 审计辞任
- 业绩对赌方主体注销 / 资产剥离

任一触发 → **立即清仓 + 重写决策卡**。

## 7. Worked Example：致尚 301486 恒扬数据收购的 7 个观察点

### 7.1 时间轴回放

| 节点 | 日期 | 反应 | 兑现概率（事后） |
|---|---|---|---|
| 停牌筹划 | 2025-04-08 | 停牌前 5 日 +12% | — |
| 复牌 | 2025-04-21 | +20% 涨停 | — |
| 重组预案披露 | 2025-05 | +10%（细节披露）| ~70%（市场预期）|
| 证监会受理 | 2025-09 | +3% | ~75% |
| 反馈意见 | 2025-12 | -2%（部分质询）| ~70% |
| **当前节点（决策日 4/28）** | **2026-04-28** | **过去 30 日 +33%** | **~60%（接近过会判定）**|
| 证监会过会判定 | 2026-07-28（T+3）| **待发生** | 同行业并购历史 ~85% |
| 完成交割 + 业绩并表 | 2026-09-30 | 待发生 | 过会后 ~95% |

### 7.2 4/28 决策日应跑事件 5 维信号

| 维度 | 假设性评分 | 解读 |
|---|---|---|
| 事件确定性 30% | 22 | 公告详尽 + 同行业并购 + 监管中性 |
| 控股股东支持度 20% | 15 | 主动停牌筹划 + 无减持 |
| 标的方资质 20% | 8 | 恒扬数据对阿里依赖 86.6% + 对赌方海纳天勤兜底 ≈ 0 |
| 时间窗口 15% | 12 | 距过会 ~3 个月，匹配中期持有 |
| 风险对冲 15% | -3 | 商誉 7.28 亿 / 备考总资产 16% + 兜底失效 |

→ **总分 ~54 分 = 低确定性**（不应 buy 但也不应做空）

### 7.3 4/28 应得出的事件附录

```
当前节点：4/28，距过会判定 ~91 天
兑现概率：~60%（监管已受理 + 反馈完成）
事件强度等级：低确定性（54 分）
路径 EV：+1.25%（节点博弈期间溢价 + 过会兑现）
联合事件 EV：4 件大事联合 ~24% × 终点 +30% = -5.9%
合并 EV：路径 + 终点最大值 = +1.25%（取路径）

决策方向：
- buy：禁止（事件分 < 60）
- skip / sell：禁止（B 强档 + 路径 EV 正）
- 唯一合规动作：watchlist + 等过会判定
```

### 7.4 这个附录如何修正原决策

**原决策**：skip / 卖出
**事件附录修正**：低确定性（54 分） + 路径 EV +1.25% + B 强档禁令 → **唯一合规动作 = watchlist**

→ 与 asset-type-classifier B 强档 / capital-flow 高控盘 +40 偏多 三条 framework 独立交叉验证，**三重阻断错判**。

### 7.5 致尚案例 L2 模型层修复完成

L2 静态 EV 模型缺路径分布权重 ~30%，本 framework 的路径 EV 模型直接修复：从"终点 EV -5.9%"升级到"路径 EV +1.25% / 最大节点 EV +30%"。这是 0.4.0-alpha.2 的核心收益。

## 8. 失效场景

### 8.1 同时多事件并行

**场景**：标的同时重组 + 实控人变更 + 监管立案。

**退路**：联合概率乘法 + 取最低事件强度作为整体强度上限。

### 8.2 事件长期反复

**场景**：3 年内 5 次重组失败 / 反复停牌复牌。

**退路**：标记"事件折扣"系数（× 0.5），降低兑现概率。

### 8.3 跨境并购（中概股）

**场景**：A 股公司并购海外标的 / 美股退市回 A 等跨境并购。

**退路**：监管套利风险 + 反垄断审查（CFIUS / 国家反垄断局）+ 中美关系背景，整体兑现率历史 ~30%，权重大幅下调。

### 8.4 SPAC DeSPAC

**场景**：美股 SPAC 寻找标的 → DeSPAC 合并完成。

**退路**：本 framework 仅作辅助，主用 us-ipo-arbitrage 三路径模型 + Lockup 抛压。

### 8.5 已平仓回看

**场景**：事件早已落地（> 12 个月），标的回归 E_value。

**退路**：退本 framework，A_event 标签解除，重新分类。

## 诚实 disclaimer

事件驱动分析是**概率推断 + 时间轴博弈**，不是确定性预测。

**核心局限**：

1. **历史兑现率 ≠ 未来兑现率**：监管口风变化（2024 年比 2018 年并购通过率显著下降）导致历史均值快速失效
2. **节点反应有方差**：典型反应 ±X% 是历史均值，单次可能 -50%（黑天鹅）也可能 +100%（超预期）
3. **联合概率非简单乘法**：4 件大事兑现概率不独立（一个失败可能拖累全部），实际联合概率比简单乘法更低
4. **路径 EV ≠ 实现收益**：用户必须在路径高点卖出才能拿到，否则回到终点 EV
5. **事件信息不对称**：内部人 / 监管 / 大股东信息领先散户 1-3 个月

**绝对禁忌**：

- 用单一历史兑现率做单笔重仓决策（至少多源验证 + 调整系数）
- 在节点真空期重仓（信息不确定 = 价格波动放大）
- 忽视黑天鹅清单（"我相信不会发生"是认知偏误）
- 把"高兑现概率"等同于"必然兑现"（即便 95% 兑现率仍有 5% 失败概率，需考虑止损）

**事件驱动是高方差策略**。本 framework 的核心价值不是"预测兑现"，而是：
1. 识别"事件未落地前不能用静态 EV"
2. 把决策从"全有 / 全无"升级为"节点 / 路径"
3. 给路径每个节点设触发条件，让操作有纪律不靠直觉

**长期持有视角下事件驱动权重 < 30%**，主要服务于 ≤ 12 个月的中短期博弈。
