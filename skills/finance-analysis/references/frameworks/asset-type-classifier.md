# Asset Type Classifier — 标的类型前置分类器

> **决策前置必跑 framework**。在任何套路 A 个股分析、套路 C 事件分析、套路 D 主题选股启动**之前**，先用本分类器给标的打标签，决定走哪条 framework 路径。
>
> **为什么需要**：用价值股 framework 切博弈股 = 工具错配。L3 framework 错配是 finance-analysis skill 历史最大单一根因（参见致尚 301486 错判，2026-04-28→05-07 偏差 +22.7%）。
>
> **核心原理**：**胜负手维度**（基本面 / 资金面 / 技术面 / 事件面 / 情绪面）随标的类型变化，必须先分类再选 framework。

---

## ⚡ When to Use / When NOT to Use（路由前必读）

| ✅ When to Use | ❌ When NOT to Use |
|---|---|
| 个股 / 主题 / 事件命题决策启动前（套路 A/C/D 第一步必跑）| **基金 / ETF / 债券分析** → 走 fund-analysis / bond-analysis 自带分类 |
| 收到任意 ticker 第一动作 | **复盘类命题（套路 E）** → 已有标签，复盘时仅做"标签是否变化"重判 |
| 标签状态可能变化时（重组过会 / 主升浪结束 / 锁仓解禁 / 业绩稳定）→ 重判 | **加密货币 / 期权 / 衍生品** → 资产类型完全不同，本分类器不覆盖 |
| 跨标的类型对比 | **跨境套利（A+H 折价 / ADR 套利）** → 走 event-driven（0.4.0）|
| 主题筛选 Top-N 后单股研究前 | **极端宏观危机期（2008 / 2020 类）** → 所有标签同时失效，top-down 切到危机模式 |

**铁律**：未跑分类器，禁止进入决策卡 / 估值 framework。这条铁律凌驾于所有 framework，覆盖 100% 套路 A/C/D 命题。

## 0. 决策树（先看这个）

```
输入：一只标的 + 决策日期
↓
Step 1: 跑 quote.sh 校准实时股价 + 数据时点（铁律 0）
↓
Step 2: 抓近 60 个交易日日线 + 同期板块指数日线（数据基础）
↓
Step 3: 7 项标签扫描（每项独立判断，可叠加）
  ├─ 标签 A: 是否在事件驱动期？（停牌/重组/收购/退市风险）
  ├─ 标签 B: 是否在主升浪 / 题材炒作中？
  ├─ 标签 C: 是否小盘 / 控盘标的？
  ├─ 标签 D: 是否次新 / IPO 锁仓期？
  ├─ 标签 E: 是否价值股 / 稳态经营？
  ├─ 标签 F: 是否周期股 / 强宏观敏感？
  └─ 标签 G: 是否困境反转 / 业绩拐点？
↓
Step 4: 按标签组合查路由表 → 输出 framework 调用清单 + 必看维度 + 可忽略维度
↓
Step 5: 输出"分类标签卡" 嵌入决策卡顶部
```

**铁律**：未跑分类器，禁止启动深度分析。这条铁律覆盖所有 framework。

## 1. 7 项标签详解

### 标签 A：事件驱动期（A_event）

**判定信号**（任一触发即标记）：

| 信号 | 阈值 |
|---|---|
| 公告披露重大资产重组（停牌→复牌）| 公告日 ± 6 个月窗口内 |
| 公告披露并购方案（未完成）| 收购协议签署 → 完成交割之间 |
| 公告披露剥离 / 出售核心资产 | 公告日 ± 3 个月窗口内 |
| 退市风险警示（*ST / ST）| 处于警示期间 |
| 实控人变更 / 控股权转让 | 公告日 ± 6 个月窗口内 |
| 重大诉讼 / 监管处罚未结案 | 处于未结期间 |

**核心特征**：**胜负手在"事件能否兑现 + 兑现时点"，不在基本面静态估值**。

**典型陷阱**：用静态 EV 模型评估事件驱动期标的 → 漏算"事件兑现路径中的期间溢价"。

---

### 标签 B：主升浪 / 题材炒作中（B_momentum）

**判定信号**（≥ 2 项触发即标记）：

| # | 信号 | 阈值 |
|---|---|---|
| B1 | 近 30 日累计涨幅 | ≥ +30% |
| B2 | 近 30 日内出现过 ≥ 1 次涨停 | 涨停板（A 股 +20% 创业板 / +10% 主板）|
| B3 | 当前股价 / 60 日 MA | ≥ 1.30（远离均线）|
| B4 | 同期板块指数累计涨幅 | < 个股累计涨幅的 50%（个股领先板块）|
| B5 | 主题热度 | 媒体覆盖 / 同概念股普涨 |
| B6 | 换手率（近 5 日均值）| ≥ 5%（高换手）|

**强度分级**（影响 framework 错配代价 + 仓位约束）：

| 命中数 | 强度等级 | 含义 | framework 错配代价 |
|---|---|---|---|
| 2 项 | **B 弱** | 边缘主升浪 | 估值锚仍可参考，但需备注"动量风险" |
| 3-4 项 | **B 中** | 典型主升浪 | 静态估值降为参考锚，主决策不可依赖 |
| 5-6 项 | **B 强** | 强主升浪 / 妖股化 | **静态估值彻底失效**，**禁止做空决策**，决策卡顶部红字标注"高错配代价区" |

**强度等级写入决策卡顶部**（与标签并列），路由时 B 强 → 必须等待 capital-flow + technical-pattern framework 落地后再出决策卡，否则只能"观望 + 标记 framework 缺位"。

**核心特征**：**胜负手在"资金博弈 + 情绪节奏 + 技术形态"，基本面已被远远抛在后面**。

**典型陷阱**：
- 用静态估值"算出贵了"做空 / 卖出 → 错过主升浪
- 用单日分时"判断顶部"做减仓 → 二次启动后踏空
- "看穿大资金"幻觉的高发区

**经典反例**：致尚 4/29 「分时倒 T 字头 = 主力出货」判断 → 实际是洗盘后主升浪第二波启动。决策日 4/28 实测 B1 ✅ +33.4% / B2 ✅ 60 日 2 次涨停 / B6 ✅ 换手 ~24% / B5 ✅ 多概念叠加 = **B 中等偏强**，错配代价已被市场以 6 日 +22.7% 兑现。

---

### 标签 C：小盘 / 控盘标的（C_smallcap）

**判定信号**（任一触发即标记）：

| # | 信号 | 阈值 | 数据源 |
|---|---|---|---|
| C1 | 总市值 | ≤ 200 亿 RMB（A 股）/ ≤ $5B（美股）/ ≤ 200 亿 HKD（港股）| quote.sh + 总股本（巨潮 / IR）|
| C2 | **流通市值（首选）** | ≤ 100 亿 RMB | 巨潮 / 东财 / 同花顺 F10 |
| C3 | 流通股本 / 总股本 | ≤ 50%（限售比例高）| 巨潮股本结构 / 限售解禁公告 |
| C4 | 大股东 + 一致行动人持股 | ≥ 40% | 季报"前十大股东"|
| C5 | 龙虎榜出现 | 近 30 日上榜 ≥ 1 次 | 深交所 / 上交所"龙虎榜数据"|

**判定优先级**：C2（流通市值） > C1（总市值） > C3 / C4 / C5。**只用 C1 + 上市时间近似估算 = 弱判定**，应在 capital-flow framework 落地前手工补查 C2 / C3。

**致尚 4/28 案例的判定盲区**：当时只有 C1（总市值 147 亿）+ 上市 < 5 年作为代理变量，**未读 C2 / C3 / C4 / C5**。如果当时读了 F10 流通股本，C 标签强度判定会更准确，资金面盲区会被更早发现。

**核心特征**：**胜负手在"主力资金动向 + 筹码集中度 + 龙虎榜"，5-10 亿资金即可控盘**。

**必看维度**：
- 龙虎榜（深交所/上交所每日披露）
- 北上资金持仓（深股通/沪股通）
- 融资余额变动
- 大股东减持 / 增持公告
- 大宗交易折溢价

**数据源占位（capital-flow 落地前手工方案）**：

| 数据 | 手工抓取路径 |
|---|---|
| 流通股本 / 限售明细 | 巨潮资讯网搜公司代码 → 公司公告 → 股本结构变动 |
| 龙虎榜 | szse.cn/disclosure/margin/margin/index.html / sse.com.cn 类似栏目 |
| 北上持仓 | hkex.com.hk → CCASS 持仓查询 / 同花顺/东财深股通栏目 |
| 融资余额 | 同花顺 F10 → 融资融券 / Wind / 东财数据中心 |

**典型陷阱**：用大盘股估值模型（PE / DCF）切控盘小盘股 → 完全忽略筹码维度。

---

### 标签 D：次新 / IPO 锁仓期（D_ipo）

**判定信号**：

| 信号 | 阈值 |
|---|---|
| 距离 IPO 上市日 | ≤ 12 个月 |
| 控股股东 / 战投 锁仓未到期 | 处于锁仓期内 |
| 首日表现 | 通常溢价 50-200% |

**核心特征**：流通盘极小 + 题材光环 + 锁仓压力。**走 hk-ipo-arbitrage / us-ipo-arbitrage / alpha-generation framework**。

**典型陷阱**：用稳态 PE 估值模型评估次新股 → 严重低估流动性溢价。

---

### 标签 E：价值股 / 稳态经营（E_value）

**判定信号**（必须全部满足）：

| 信号 | 阈值 |
|---|---|
| 上市时间 | ≥ 5 年 |
| 近 3 年营收同比波动 | ≤ ±15% |
| 近 3 年净利同比波动 | ≤ ±20% |
| ROE（近 3 年均值）| ≥ 8% |
| 近 30 日累计涨幅 | < +20% |
| 不在事件驱动期（标签 A 未触发）|
| 不在主升浪期（标签 B 未触发）|

**核心特征**：**胜负手在"基本面 + 估值"，资金面 / 技术面影响有限**。这是**唯一适用静态 EV 模型的类型**。

**适用 framework**：valuation-relative / valuation-dcf / alpha-generation。

---

### 标签 F：周期股 / 强宏观敏感（F_cyclical）

**判定信号**（任一触发即标记）：

| 信号 | 行业范例 |
|---|---|
| 大宗商品 | 钢铁 / 煤炭 / 石化 / 有色 |
| 资本品 | 工程机械 / 航运 / 化工 |
| 房地产产业链 | 地产 / 建材 / 家电 |
| 强利率敏感 | 银行 / 保险 / 券商 |
| 半导体周期 | 存储 / 设备 / 代工 |

**核心特征**：**胜负手在"行业景气位置 + 宏观周期 + 库存周期"，单股基本面 ≠ 决定性**。

**适用 framework**：top-down-selection（自上而下）+ valuation-relative（PB 而非 PE）。

**典型陷阱**：用 PE 估值切周期股 → 周期顶部 PE 最低（因为利润最高），周期底部 PE 最高 → 完全反向。

---

### 标签 G：困境反转 / 业绩拐点（G_turnaround）

**判定信号**（≥ 2 项触发）：

| 信号 | 阈值 |
|---|---|
| 近 2-3 年净利亏损 → 单季扭亏 | 最近一季 GAAP 净利由负转正 |
| 营收增速止跌回升 | 同比连续 4 季 < 0% → 转正 |
| 毛利率 / 净利率 | 季度环比改善 ≥ 2pt |
| 行业整体出清 | 同行 ≥ 30% 退出 / 减产 |
| 估值历史分位 | < 20% |

**核心特征**：**胜负手在"拐点真实性 + 持续性"，市场对拐点高度敏感**。

**适用 framework**：earnings-deep-dive + valuation-relative（PB 锚）+ alpha-generation。

## 2. 标签组合 → Framework 路由表

| 标签组合 | 标的类型描述 | 主框架（必跑）| 辅框架（建议）| 必看维度 | 可降权 |
|---|---|---|---|---|---|
| **A + B + C** | 重组+主升浪+小盘（致尚画像）| **capital-flow（待建）+ event-driven（待建）** | ai-thematic-investing | **资金面 / 技术面 / 事件节奏** | 静态估值 |
| A + C | 重组+小盘 | event-driven + valuation-relative（PB）| alpha-generation | 事件节奏 / 龙虎榜 | 静态 PE |
| B + C | 主升浪+小盘 | capital-flow + technical（待建）| ai-thematic | 量价 / 龙虎榜 / 板块强度 | 静态估值 |
| B + 主题龙头 | 主升浪+赛道龙头 | ai-thematic-investing + valuation-dcf | top-down-selection | 主题节奏 / 业绩兑现 | — |
| D | IPO / 次新 | hk-ipo-arbitrage 或 us-ipo-arbitrage | alpha-generation | 锁仓 / 流动性 | 稳态 PE |
| **E** | 稳态价值股 | **valuation-relative + valuation-dcf** | alpha-generation | 财报 / 估值历史分位 / 分红 | 短期资金面 |
| F | 周期股 | top-down-selection | valuation-relative（PB）| 行业景气 / 库存周期 | 单期 PE |
| G | 困境反转 | earnings-deep-dive | valuation-relative（PB）| 拐点持续性 / 现金流 | 历史 PE |
| **B + D** | IPO 后主升浪 | hk-ipo-arbitrage + ai-thematic | alpha-generation | 锁仓节奏 / 主题热度 | 稳态估值 |
| A + G | 重组拯救困境 | event-driven + earnings-deep-dive | — | 重组兑现 / 商誉风险 | — |

**铁律 1**：**标签组合内含 A 或 B 时，禁止使用 valuation-relative / valuation-dcf 作为唯一决策依据**。静态估值仅作为参考锚，不作 EV 主模型。

**铁律 2**：**标签组合内含 C（小盘）时，必须看资金面（龙虎榜 / 北上 / 融资）**。否则分析维度严重缺失。

## 4. 输出：分类标签卡

每次决策必须在决策卡顶部填这张卡：

```markdown
## 标的类型分类（asset-type-classifier 输出）

**触发标签**：[A_event] [B_momentum 强度=中/B 中] [C_smallcap 弱判定]（按强度从高到低，标注强度等级与判定置信度）

**B 强度判定明细**（命中数 = 4/6）：
- ✅ B1 近 30 日累计 +33.4%（≥ 30%）
- ✅ B2 近 60 日 2 次涨停
- ✅ B5 多概念叠加（AI / CPO / Switch 2）
- ✅ B6 近 5 日均换手估 ~24%
- ❌ B3 当前价/MA60 = ___（待算）
- ❌ B4 板块对比 = ___（待算）

**C 判定置信度**：弱（只读到 C1 总市值，未读 C2/C3/C4/C5 → 需手工补查）

**画像描述**：重组期 + 主升浪 + 小盘股三重叠加 → **博弈型标的**

**主框架**：capital-flow + event-driven（待建，本次降级用 ai-thematic-investing）

**辅框架**：ai-thematic-investing

**必看维度（缺失 = 作废）**：
- ✅ 资金面：近 5 日龙虎榜 / 北上持仓变动 / 融资余额
- ✅ 技术面：近 30 日量价 / 主升浪所处阶段（一波 / 洗盘 / 二波）
- ✅ 事件节奏：重组进度（停牌 → 复牌 → 预案 → 过会 → 并表）
- ✅ 板块强度：同概念股表现 / 板块指数走势

**可降权维度**：
- ⬇️ 静态 PE / DCF（事件驱动期不可信）
- ⬇️ 单日分时形态（主升浪期信号噪声极高）

**冲突检查（必勾）**：
- [ ] 我是否在用基本面反推"市场错了"？（高危幻觉，参考 feedback_narrative_coverage_vs_mispricing）
- [ ] 我是否在用单日分时判断主力意图？（B 标签下高危）
- [ ] 我是否在用静态 EV 评估事件驱动标的？（A 标签下高危）

**适用框架替代提醒**：当前选择的框架是 ___，类型组合 ___，是否冲突？冲突说明：___
```

## 5. Worked Example：致尚 301486（4/28 决策日错配复盘）

### 5.1 当时的真实状态（应当被识别）

| 维度 | 致尚 4/28 实际数据 |
|---|---|
| 总市值 | ~147 亿（流通市值更小）|
| 上市时间 | 2023-08（< 5 年）|
| 4/8 公告 | 停牌筹划恒扬数据收购 |
| 4/21 复牌 | +20% 涨停 |
| 4/22-4/28 走势 | 高位震荡 + 中阴洗盘 |
| 近 30 日累计涨幅 | +20%（4/20 174.22 → 4/28 202.86）|
| 主题标签 | AI 算力 + CPO + Switch 2 + 越南 |
| 板块同期表现 | AI 算力链普涨 |

### 5.2 应当触发的标签

| 标签 | 触发依据 | 是否应触发 |
|---|---|---|
| A_event | 4/8 停牌 + 重组未完成 | ✅ |
| B_momentum | 30 日 +20% + 涨停 + 主题热度 + 多概念叠加 | ✅ |
| C_smallcap | 总市值 < 200 亿 + 上市 < 5 年（流通盘小）| ✅ |
| D_ipo | 上市 ≥ 12 个月 | ❌ |
| E_value | 上市 < 5 年 + 高位 | ❌（**关键：决策时实际走的是 E 路径**）|
| G_turnaround | Q1 扣非 -894 万（不是反转）| ❌ |

**正确画像**：A + B + C 三重叠加 = 博弈型标的

**应走 framework**：capital-flow + event-driven + ai-thematic（辅）

**实际走的 framework**：valuation-relative + ai-thematic + 命题驱动套路 A → 完全错配

### 5.3 错配后果

| 维度 | 应做 | 实际做 |
|---|---|---|
| 资金面 | 应看龙虎榜 / 北上 / 融资 | ❌ 完全没看 |
| 技术面 | 应识别"洗盘 vs 出货" | ❌ 4/29 用倒 T 字头判主力出货（错） |
| 事件节奏 | 应判定主升浪所处阶段 | ❌ 当稳态公司分析 |
| 估值锚 | 应作参考，不作主决策 | ❌ 用静态 EV -5.9% 作主决策依据 |

### 5.4 偏差量化

| 项 | 我的判断 | 实际（4/28→5/7 早盘）|
|---|---|---|
| 6 日累计涨幅预期 | < 0% | +22.7% |
| 相对创业板指 α | 跑输 | 跑赢 +17.3pt |
| EV | -5.9% | 短期实测 +22.7% |

**核心教训**：错配 framework → 即便基本面分析全对（福可喜玛已剥离 / 4 件大事联合概率 24% 算对）→ 决策结论仍然错。**framework 选择 > 分析深度**。

## 6. 标签更新机制（动态分类）

**原则**：标签不是一次性打的，**每次复盘都要重判**。

| 触发场景 | 重判标签 |
|---|---|
| 重组方案过会 | A_event 解除（或转为 G_turnaround）|
| 主升浪结束（30 日累计回撤 > 20%）| B_momentum 解除 |
| 流通市值升至 200 亿+ | C_smallcap 解除 |
| 锁仓全部解除 | D_ipo 解除 |
| 业绩连续 4 季稳定 | 转为 E_value |

**触发动作**：
- 标签变化时立即重抓数据 + 重选 framework
- 旧的决策卡作废，新建决策卡
- 新决策卡顶部说明"由 X 标签转为 Y 标签 → framework 切换"

## 7. 失效场景

本分类器**不适用**于：

| 场景 | 原因 | 替代方案 |
|---|---|---|
| 加密货币 | 资产类型完全不同 | 待 0.5.0 crypto-thematic |
| 期权 / 衍生品 | 定价机制完全不同 | 本 skill 不覆盖 |
| 私募股权 / 一级市场 | 流动性维度完全不同 | 本 skill 不覆盖 |
| 跨境套利（A+H 折价 / ADR）| 套利 framework | 待 0.4.0 event-driven |
| 极端宏观危机期（如 2008 / 2020）| 所有标签同时失效 | top-down-selection 切到危机模式 |

**主升浪结束的判定难度**：B 标签解除时点判断错误是次高频错判。建议结合 MA 系统 + 量能萎缩 + 板块退潮信号联合判断（待 technical framework 0.4.0）。

## 诚实 disclaimer

本分类器是**降低 L3 framework 错配概率**的前置工具，不是"算得更准"的工具。即使分类正确，仍可能因数据缺失 / 认知偏误 / 时机判断错误而决策失败。

但**用错 framework = 几乎注定失败**——这是过去案例的强证据（致尚 4/28 偏差 +22.7%，全程基本面分析无误）。

framework 选择 > 分析深度。
