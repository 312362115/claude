# 资金面分析（Capital Flow）

> **小盘控盘标的的核心 framework**。当 asset-type-classifier 触发 C_smallcap 标签，本 framework 是必看维度（缺失 = 分析作废）。
>
> 核心命题：**主力资金的方向 + 控盘度 + 异动信号**，不是"基本面是否合理"。
>
> **认知基础**：A 股 / 港股小盘股的胜负手 80% 在资金面，20% 在基本面（致尚 301486 案例直接教训）。基本面分析在小盘股上的边际收益快速递减，资金面分析的边际收益持续上升。

---

## ⚡ When to Use / When NOT to Use（路由前必读）

| ✅ When to Use | ❌ When NOT to Use |
|---|---|
| C_smallcap 标签触发（总市值 ≤ 200 亿 RMB / ≤ $5B / ≤ 200 亿 HKD）| 大盘蓝筹（总市值 > 1000 亿 + 流通盘 > 500 亿）→ 资金面信号被稀释，意义有限 |
| B_momentum 中/强档 + C_smallcap → 双标签强相关 | 美股大盘 ETF 成分股 → 资金面被指数 + 篮子交易主导 |
| A_event 触发（重组/收购未完成）+ 小盘 → 看资金提前埋伏 | E_value 稳态价值股 → 走 valuation-relative，资金面是次要参考 |
| 龙虎榜异动后判断"主力买/卖" | F_cyclical 周期股 → 走 top-down-selection 看行业景气，资金面噪声大 |
| 北上单日加仓 / 减仓异动判断 | D_ipo 锁仓期 → 走 hk/us-ipo-arbitrage，本 framework 用作辅助 |
| 融资余额暴增 / 暴跌信号判断 | 已停牌标的 → 等复牌再启动 |
| 大宗交易折/溢价信号 | 流通盘极小（< 5 亿）的妖股 → 信号失真，**禁止参与** |

**强制路由触发条件**：asset-type-classifier 输出包含 C_smallcap 标签，**本 framework 是必跑项**。跳过 = 0.3.2 流程违规。

## 1. 决策树

```
输入：标的 + asset-type-classifier 输出（含 C_smallcap）
↓
Step 1: 确认流通盘量级（必要数据，不可估算）
  ├─ 流通市值 ≤ 50 亿 → 极小盘，5 亿资金可控盘
  ├─ 流通市值 50-100 亿 → 小盘，10-20 亿资金可控盘
  ├─ 流通市值 100-200 亿 → 中小盘，30-50 亿资金可主导
  └─ > 200 亿 → 退本 framework，C 标签判定有误
↓
Step 2: 控盘度评估（5 项加权）
  ├─ 前十大股东持股比 + 限售比例
  ├─ 北上 / 沪深股通持仓比
  ├─ 公募 / 私募 / 险资机构持仓比
  ├─ 融资余额 / 流通市值
  └─ 实际可流通筹码 = 流通盘 × (1 - 控盘度)
↓
Step 3: 主力方向识别（4 维信号）
  ├─ 龙虎榜（近 5 / 30 日上榜频率 + 净买入 + 席位类型）
  ├─ 北上资金（5 / 20 日净买入 + 持股变化%）
  ├─ 融资余额（5 / 20 日变动）
  └─ 大宗交易（折溢价 + 受让方）
↓
Step 4: 异动信号识别（决定操作时点）
  ├─ 涨停板封板度（封单金额 / 流通市值 ≥ X%）
  ├─ 量比异动（当日量 / 5 日均量 ≥ 3）
  ├─ 板块联动度（同概念股普涨 / 个股领涨）
  └─ 龙虎榜机构席位入场 / 退出
↓
Step 5: 输出资金面附录（嵌入决策卡）
  ├─ 控盘度等级（高/中/低）
  ├─ 主力方向（流入/流出/分歧）
  ├─ 异动等级（强/中/弱/无）
  └─ 操作建议（埋伏 / 跟进 / 撤离 / 观望）
```

## 2. 量化信号 — 5 大维度

### 2.1 龙虎榜（Top-Buyer/Seller List）

**触发上榜规则**（A 股）：
- 涨/跌幅偏离值 ±7%（创业板/科创板 ±10%）
- 换手率 ≥ 20%
- 单日振幅 ≥ 15%

**关键字段**：

| 字段 | 数据源 | 阈值意义 |
|---|---|---|
| 买一买五净买额 | 深交所/上交所披露 | 净买额 / 流通市值 ≥ 0.5% = 主力主导 |
| 卖一卖五净卖额 | 同上 | 净卖额 / 流通市值 ≥ 0.5% = 主力派发 |
| 机构席位（买方）| "机构专用"标识 | 机构净买 ≥ 2 席 = 强信号 |
| 知名游资席位 | 主力游资监测 | 拉萨军团 / 章盟主 / 宁波桑田路 等头部游资 |
| 沪/深股通席位 | "沪股通"/"深股通"标识 | 北上资金动向（机构属性强）|

**A 股龙虎榜判读**：

```
主力净买入 = (买1+买2+...+买5) - (卖1+卖2+...+卖5)
机构席位数（买方 - 卖方）
游资席位类型（一线 / 二线 / 新兴）

判断：
  主力净买入 > 0 + 机构席位净 +1 以上 = 看好
  主力净买入 < 0 + 机构席位净 -1 以下 = 派发
  主力净买入震荡 + 游资接棒 = 短线博弈
```

**港股龙虎榜替代**：
- HKEX 不强制公开龙虎榜
- 替代信号：CCASS 持仓变动（每日披露各券商持仓变化）
- 关注：摩根大通 / UBS / 高盛等机构席位变动

**港股 CCASS 判读**：
```
单日某券商持股 ≥ 5% 流通盘 → 主力席位
单日券商净增持 / 流通市值 ≥ 0.3% → 异动
连续 3 日同一席位增持 → 主力布局
```

---

### 2.2 北上 / 沪深股通持仓

**数据源**：
- 港交所 CCASS：hkex.com.hk（深股通 / 沪股通持仓查询）
- 东财数据中心 / 同花顺 F10「沪深股通」栏目

**关键指标**：

| 指标 | 阈值 | 解读 |
|---|---|---|
| 持股比例 | ≥ 5% 流通股本 | 北上重仓股，强主力信号 |
| 单日加仓% | +1% / 单日 | 强买入信号 |
| 5 日累计加仓% | +5% / 5 日 | 中期看好 |
| 20 日累计加仓% | +10% / 20 日 | 长期建仓中 |
| 单日减仓% | -1% / 单日 | 强卖出信号 |
| 5 日累计净流出% | -5% / 5 日 | 中期撤退 |
| 持仓比例触及历史 90 分位 | — | 接近顶部，警惕 |

**北上的特殊性**：
- 信息相对前置（机构主导，决策慢但持仓稳）
- A 股小盘股北上重仓 = 机构认证
- **反向信号同等强**：北上集中减仓的小盘股短期大概率不及大盘

---

### 2.3 融资余额变动

**数据源**：
- 同花顺 F10 → 融资融券
- 东财数据中心 → 融资融券明细
- Wind / iFind（专业数据源）

**关键指标**：

| 指标 | 阈值 | 解读 |
|---|---|---|
| 融资余额 / 流通市值 | ≥ 5% | 融资主导股，杠杆资金活跃 |
| 单日融资买入额 / 当日成交额 | ≥ 15% | 融资盘强力推动 |
| 5 日融资余额变动% | +20% / 5 日 | 融资暴增，警惕高位接盘 |
| 5 日融资余额变动% | -20% / 5 日 | 融资暴跌，可能爆仓平仓 |
| 融资融券比 | > 5 | 多头主导（融资远大于融券）|

**融资盘的特殊性**：
- **杠杆双刃**：上涨时放大，下跌时强制平仓
- 融资余额暴增 + 股价高位 = **后续杀跌动能极强**
- 融资余额暴跌 + 股价低位 = **可能错杀机会**
- 主升浪后期看融资 / 流通市值比，> 8% 进入风险区

---

### 2.4 大宗交易（Block Trade）

**数据源**：交易所每日披露大宗交易明细

**关键字段**：

| 字段 | 阈值 | 解读 |
|---|---|---|
| 折价率 | < -5% | 折价大宗 = 大股东 / 机构急于变现 |
| 溢价率 | > 0% | 溢价大宗 = 战略性接盘 / 利好预期 |
| 受让方席位 | 机构 vs 营业部 | 机构受让 = 长线，营业部 = 短炒 |
| 大宗成交额 / 当日成交额 | > 10% | 重大资金腾挪 |
| 同一标的连续 5 日大宗 | — | 大股东批量减持征兆 |

**致命陷阱**：大宗交易的成交价 ≠ 真实股价。本 skill 铁律 0 已沉淀（沪电案例 / 致尚案例），**禁止把大宗成交价当股价用**。

---

### 2.5 流通股本 / 限售解禁

**数据源**：巨潮资讯网 → 公司公告 → 股本结构变动

**关键指标**：

| 指标 | 解读 |
|---|---|
| 流通股本 / 总股本 | < 50% = 高限售比例（次新股常见）|
| 限售解禁日期（180 日 / 1 年 / 3 年）| 解禁日 ± 30 日是抛压窗口 |
| 解禁股数 / 流通股本 | > 50% = 重大抛压，应规避 |
| 大股东 + 一致行动人持股 | ≥ 40% = 高控盘 |
| 高管 / 员工持股计划 | 持股 + 解禁 = 共同利益博弈 |

**限售解禁抛压模型**：

```
预期抛压 = 解禁股数 × 解禁日股价 × 减持意愿系数

减持意愿系数（经验值）：
- 控股股东 + 战投：0.3-0.5（需保持控制权）
- 财务投资人 / PE：0.7-0.9（落袋为安）
- 员工持股 / 高管：0.5-0.7（部分套现）
- 限售股 + 业绩对赌未达：0.9（强减持）
```

## 3. 控盘度评分模型（百分制）

**控盘度 = 主力可控筹码占比**

| 维度 | 权重 | 计算 |
|---|---|---|
| 大股东 + 一致行动人持股 | 30 | 持股比例 × 100 / 0.50（50% 为满分）|
| 北上 / 沪深股通持股 | 20 | 持股比例 × 100 / 0.10（10% 为满分）|
| 公募 / 私募 / 险资机构持股 | 20 | 同上口径，10% 为满分 |
| 融资余额 / 流通市值 | 15 | 比例 × 100 / 0.10（10% 为满分）|
| 高管 + 员工持股计划 | 15 | 比例 × 100 / 0.05（5% 为满分）|

**得分等级**：

| 总分 | 等级 | 含义 |
|---|---|---|
| ≥ 80 | 极高控盘 | 主力意图主导股价，基本面影响 < 20% |
| 60-80 | 高控盘 | 主力影响显著，需重点跟踪资金动向 |
| 40-60 | 中等控盘 | 资金面与基本面博弈 |
| < 40 | 低控盘 | 资金面信号噪声大，回归基本面分析 |

## 4. 主力方向 EV 模型（4 维加权）

**主力方向得分** ∈ [-100, +100]：

```
方向得分 = 龙虎榜分(±30) + 北上分(±25) + 融资分(±25) + 大宗分(±20)

判断：
  ≥ +50  → 强买入（主力主导拉升中）
  +20 ~ +50 → 偏多（主力有动作但分歧）
  -20 ~ +20 → 中性（主力观望或分歧）
  -50 ~ -20 → 偏空（主力撤退中）
  ≤ -50  → 强卖出（主力主导杀跌）
```

**EV 修正**（在估值 EV 基础上叠加）：

```
基础 EV = 估值 EV（来自 valuation-card / asset-type-classifier）

资金面修正系数：
  方向得分 ≥ +50 → ×1.5（短期主力推动）
  方向得分 +20~+50 → ×1.2
  方向得分 -20~+20 → ×1.0（不变）
  方向得分 -50~-20 → ×0.7
  方向得分 ≤ -50 → ×0.5（短期主力压制）

调整后 EV = 基础 EV × 修正系数

注意：修正系数仅适用于 ≤ 1 个月的短期 EV，> 3 个月退基本面 EV
```

## 5. 执行纪律（最易翻车环节）

### 5.1 三条铁律

**铁律 1：不在融资余额 / 流通市值 > 8% 时高位追入**
- 主升浪末期典型信号，杠杆已极度集中
- 反向触发概率高，跌幅放大

**铁律 2：北上连续 5 日净流出，禁止逆势抄底**
- 机构资金信息相对前置，判断错的概率低
- 等北上转正再考虑

**铁律 3：龙虎榜机构席位连续 3 次卖方出现，立即减仓**
- 机构集体撤退是重大警报
- 不论基本面多好，机构有非公开信息优势

### 5.2 数据时效要求

| 数据 | 更新频率 | 决策时效 |
|---|---|---|
| 龙虎榜 | T 日 17:00-18:00 后 | 用 T 日数据指导 T+1 决策 |
| 北上持仓 | T 日 16:00 后 | 同上 |
| 融资余额 | T 日 17:00-18:00 后 | 同上 |
| 大宗交易 | T 日 18:00 后 | 同上 |
| 流通股本 / 解禁 | 公告日 | 解禁日提前 30 日预警 |

**绝对禁止**：用周末 / 假期前夕数据做下周一开盘决策（信号已过期 2-3 天）。

### 6.1 当时未跑本 framework 的盲区

致尚 4/28 决策时**完全没看资金面**（asset-type-classifier 0.3.2 后明确禁止）。如果当时跑了 capital-flow，应该看到：

### 6.2 应抓的 5 维数据

| 数据 | 应抓内容 | 工具 |
|---|---|---|
| 流通股本 | 总股本 7235 万 / 流通股 ≈ ? | 巨潮 F10 股本结构 |
| 龙虎榜 | 4/21 涨停 +20% 后必上榜，看买卖席位 | szse.cn 龙虎榜 |
| 北上 | 致尚是否在深股通？持仓变动 | 同花顺深股通栏目 |
| 融资余额 | 4/8 停牌 → 4/21 复牌后融资暴增？ | 同花顺 F10 融资融券 |
| 大宗交易 | 4/10 出现的"大宗 135 元"已沉淀（铁律 0 沪电案例），但当时未识别 | 交易所披露 |

### 6.3 控盘度评分（假设性回放）

假设当时数据（待用户实测填充）：
- 大股东 + 一致行动人 ~50% → 30 分
- 北上持仓估算 ~3% → 6 分
- 机构持仓估算 ~5% → 10 分
- 融资余额 / 流通市值 估算 ~6% → 9 分
- 高管 / 员工持股 ~4% → 12 分

→ **总分 ~67 分 = 高控盘等级**

### 6.4 主力方向得分（假设性）

- 龙虎榜：4/21 涨停 + 4/27 振幅 15%，可能上榜，机构席位 → 假设 +20
- 北上：30 日 +33% 行情中，北上加仓概率高 → 假设 +15
- 融资：复牌后融资买入活跃 → 假设 +15
- 大宗：4/10 大宗 135 元（折价 35%）→ -10

→ **总分 ~+40 = 偏多（主力有动作但分歧）**

### 6.5 应得出的资金面附录

```
控盘度等级：高（67 分）
主力方向：偏多（+40 分）
异动等级：强（30 日 +33% + 多次涨停）
操作建议：跟进观察 / 不做空
```

### 6.6 这个附录如何修正决策

**原决策**：skip / 卖出
**资金面附录修正**：高控盘 + 主力偏多 + 强异动 → **不应做空决策**

→ 与 asset-type-classifier 0.3.2 的"B 强档禁止做空"独立交叉验证，**两条 framework 共同阻断错判**。

### 6.7 核心教训

致尚案例的 framework 错配是 ~40% 权重，**资金面维度缺失是另外 ~10%**（L5 维度缺失）。0.3.2 解决了 framework 错配，0.4.0 capital-flow 解决维度缺失。两者叠加，致尚类错判从源头被双重阻断。

## 7. 失效场景

### 7.1 数据缺失

**场景**：港股小盘股没有龙虎榜，CCASS 数据延迟，融资融券机制不同。

**退路**：
1. 港股以 CCASS 持仓变动 + 卖空数据为主
2. 不用 A 股相同阈值（港股流动性 / 杠杆机制不同）
3. 标注"数据维度受限，置信度降级"

### 7.2 极端情绪期

**场景**：板块整体涨停潮 / 暴跌潮（如 2024-09 中国资产估值修复行情）。

**退路**：
1. 个股资金面信号被板块洪流稀释
2. 退 top-down-selection 看板块轮动节奏
3. 资金面降为"参考"权重，时间维度缩短

### 7.3 控盘度过高反向陷阱

**场景**：单一席位持股 > 70%（接近退市线 30% 公众持股要求）。

**退路**：
1. 退市风险 / 流动性枯竭风险 / 操纵嫌疑
2. 机构资金不愿进入
3. **直接 skip**，不参与

### 7.4 妖股化（B_momentum 强档 + 流通盘极小）

**场景**：流通盘 < 5 亿 + 主升浪 +200% 以上 + 媒体头条覆盖。

**退路**：
1. 资金面信号失真（情绪溢价主导）
2. 任何方向都可能反向 50% 以上
3. **直接 skip**，不参与

### 7.5 短期事件冲击

**场景**：突发利空 / 利好（停牌 / 重大处罚 / 业绩爆雷 / 收购意向）。

**退路**：
1. 资金面信号被事件主导
2. 退 event-driven framework（0.4.0 待建）
3. 等事件落地 + 复盘 5 个交易日后再启动 capital-flow

## 诚实 disclaimer

资金面分析的本质是**信号识别 + 概率推断**，不是预测。

**核心局限**：
1. **数据滞后**：龙虎榜 / 北上 / 融资数据都是 T 日盘后披露，T+1 决策已是"看着后视镜开车"
2. **信号噪声**：单日数据可能是临时调仓，至少看 5-20 日趋势
3. **席位伪装**：游资可能用多个营业部分散下单规避龙虎榜，机构可能用席位拆分
4. **A 股监管套利**：部分主力会故意在某日被动上龙虎榜以"晾筹码"误导散户

**绝对禁忌**：
- 用资金面信号取代基本面分析（即便强 C_smallcap 标签下，基本面仍是长期决定因素）
- 用单日资金面信号做 T+1 重仓决策（至少 5 日均线 + 多维交叉验证）
- 把"主力流入"当成 100% 上涨保证（主力可能错判 / 主力可能对倒诱多）

**资金面是辅助决策工具，不是决策主宰**。本 framework 主要用于：
1. 确认 / 否定其他 framework 的决策方向
2. 把握短期（≤ 1 个月）操作时点
3. 识别异动信号触发"需重新评估"

**长期投资（> 6 个月）以基本面 + 估值 + 行业景气为主，资金面权重 < 20%**。
