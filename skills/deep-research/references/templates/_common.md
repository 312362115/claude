# 报告结构 — 通用章节参考组合

> **这是参考组合，不是必备清单**。各调研类型 templates/`<类型>`.md 是已被验证的常见骨架——按命题实际需要选用章节。
> 章节是否存在的判断标准是 SKILL.md 5.2 的"按命题类型的章节选用矩阵"——简单事实查询不出报告，对比类按需裁剪，复杂研究/超深度走完整结构。

通用部分（Executive Summary、假设验证、反面观点、结论与建议、数据附录、参考资料）在 SKILL.md 中已定义，此处不重复。

「现状基线」和「反面观点与回应」是复杂研究 / 超深度的底层逻辑——简单/对比类按 SKILL.md 5.2 选用矩阵裁剪。

---

## 现状基线（通用章节模板）

**复杂研究 / 超深度报告必备**（对比类推荐，简单事实可省）。位置在背景/概述之后、正文分析之前。

```markdown
## 现状基线

### 内部现状
基于内部数据源（代码库 / 文档 / BI 数据 / 用户口述）梳理的当前状态。
无内部数据时标注「本报告基于公开数据」。

### 对标基准
用于对比的行业标准 / 竞品水位 / 最佳实践来源及说明。
```

---

## 反面观点与回应（通用章节模板）

**复杂研究 / 超深度报告必备**（对比类按需选用，简单事实可省）。位置在正文分析之后、结论/建议之前。

```markdown
## 反面观点与回应

对核心结论的主要反对意见及回应：
- **反面观点 1**：...（来源）→ **回应**：...
- **反面观点 2**：...（来源）→ **回应**：...
```

---

## 使用说明

1. 先按 SKILL.md "调研深度判断"确定命题类型（简单事实 / 对比类 / 复杂研究 / 超深度），决定走哪些章节
2. 再根据调研类型（技术选型 / 行业分析 / 概念研究 / 性能评测 / 竞品分析 / 可行性探索）选对应骨架——这些是**参考组合**，按内容裁剪
3. 章节按实际内容增减——不是每个小节都必须填满，没内容就删
4. 如果命题跨多个类型，以主要类型的骨架为基础，按需融入其他类型的章节
5. **Markdown 模式**：图表占位符（`![xxx](assets/xxx.png)`）根据实际生成的图表路径替换
   **HTML 模式**：参照 `references/html-report-template.html` 模板编写报告，图表用 `.chart-container` 内嵌 HTML/SVG
6. 表格中的数据根据实际调研结果填充
7. 「现状基线」和「反面观点与回应」是复杂研究 / 超深度的底层逻辑——简单/对比类按 SKILL.md 5.2 选用矩阵决定是否需要。无内部数据时在「现状基线」中标注「基于公开数据」即可
